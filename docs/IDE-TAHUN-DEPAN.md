# Ide untuk tahun berikutnya

Tempat menaruh ide bagus yang **tidak** dikerjakan tahun ini.

Menuliskannya di sini bukan penolakan, melainkan cara menjaga jadwal tetap hidup. Cakupan yang melebar adalah penyebab paling umum penelitian pengembangan tidak selesai — dan ide yang tercatat rapi justru lebih mungkin dikerjakan pada tahun ke-2 sampai ke-5 peta jalan daripada ide yang dipaksakan masuk sekarang lalu setengah jadi.

## Sudah ditetapkan di luar cakupan tahun pertama

- Tutor AI/LLM percakapan — biaya API berulang, beban validasi etik, tidak diminta proposal
- Kelas daring sinkron / video konferensi
- Materi di luar transformasi geometri
- Gamifikasi penuh dengan papan peringkat kompetitif
- Aplikasi native Android/iOS — PWA sudah memenuhi kebutuhan
- Integrasi Dapodik atau SSO Belajar.id — impor CSV cukup untuk 3 sekolah
